# Test 4 · The Prediction — scoring sheet

Applies TEST-METHOD.md §4. Source for all wording: research file A §6 (1997 text confirmed via Open Library search-inside; page numbers not visible).

**Scoring rule for "around year X".** The method did not define a tolerance, so this clarification was written before any row was scored and is logged in TEST-METHOD §7:
- **hit:** within ±2 years
- **partial:** within ±3–5 years
- **miss:** more than 5 years off, or the stated deadline passed without the event
- **not yet due:** window still open

**Which event counts.** To keep our own judgement out, we use the event **the authors themselves later named**; where they have named none, the row is "cannot score".
